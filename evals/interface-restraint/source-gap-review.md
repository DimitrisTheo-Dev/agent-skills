# Source review and adopted changes

Reviewed 2026-11-11 against the existing Vibe UI, Studio, specialist and quality-gate instructions. Primary instructions were inspected where a directory linked to another author's repository. These are editorial design references, not validated guarantees. No external skill scripts or workflow were installed.

The read-only-value rule also comes from this project's observed failure, not a claim that the third-party sources prescribe this exact UI. A command appeared editable, checkmarks appeared to report completion and colored tiles suggested distinct app identities. UI UX Patterns now checks perceived behavior; UI Geometry checks icon source/purpose and the whole group's footprint; the quality gate explicitly inspects those relationships. Vibe UI carries the feedback and source boundaries. Studio already routes through these skills and the gate, so duplicating their rules inside Studio would add overlap.

## Applied to the example

- Removed four fabricated app marks, the duplicated large header mark and redundant header ornament.
- Kept only functional Lucide glyphs, with original source hashes and license attribution in the example.
- Replaced the full-width command panel with selectable code and an adjacent Copy button, close to its title. Copy uses a stable label width and an accessible group name.
- Replaced completion-looking checkmarks with neutral bullets; reduced pane width and related gaps while retaining readable text and touch targets.
- Preserved the frozen four-skill data, source links and installation commands. Included invocation text in search after an actual copy/paste check exposed a missed query case.
