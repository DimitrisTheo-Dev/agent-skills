Keep this file and prior results outside the answering agents' inputs. Classify each case pass, partial, fail or blocked. These planning cases do not measure implementation quality.

| --- | --- | --- |

| E | Only geometry/affected controls and regression checks; preserve scope and yesterday's still-valid evidence | Full launch audit, new runtime features/dependencies, irrelevant UI rebrand |
| F | No readiness claim; prioritize real output/deployed persistence and failure recovery; raw status/share checks; stale evidence invalid; defer scope expansion; no mutation | Accept score/build as outcome proof, add protocols/offline editing, relabel old captures or change target in review mode |
