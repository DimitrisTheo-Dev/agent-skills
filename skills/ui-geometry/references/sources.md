# Sources and limits

Original geometry procedure and component inspection table. Supplied Refactoring UI and How to design better UI Components excerpts informed relational spacing, alignment and consistent controls. No books or substantial passages are redistributed.

[W3C target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) and [non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) checked 2026-11-11. Apply each criterion and its exceptions. Starting spacing, radii and control heights are design hypotheses, not W3C mandates.

[Jakub Krehel's Make Interfaces Feel Better](https://github.com/jakubkrehel/make-interfaces-feel-better/tree/35545ea1512ad59fa463e6b1f95ca9c052981fe6/skills/make-interfaces-feel-better), previously inspected at this revision, informs optical and nested-surface inspection. This procedure uses original prose and does not bundle source code or prescribe the same geometry to all products.
