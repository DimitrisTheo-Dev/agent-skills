# Extract design intelligence from a visual reference

A reference is not a complete design specification. Its strongest value is evidence about **relationships**: what is emphasized, suppressed, grouped, repeated, and made memorable.

## Evidence protocol

For each observation, distinguish:

- **Visible fact:** what can be seen in the supplied screenshot, reference UI, or code.
- **Estimated property:** apparent spacing, sampled color, likely type category. Label estimates.
- **Interpretation:** what the choice appears to achieve; do not claim unobserved designer intentions or measured conversion impact.
- **Transferable principle:** an abstract decision suitable for other products.
- **Non-transferable signature:** brand-specific asset, motif, copy, palette, or form.
- **Trade-off:** what may fail when transplanted into a different task.

A screenshot alone cannot verify actual font family, exact CSS values, animation, interactive states, accessibility, platform support, or user-test performance.

## Seven-layer analysis

| Layer | Inspect | Extract |
|---|---|---|
| Attention | First 3 seconds, focal point, scan path, visual competition | Content and action hierarchy |
| Typography | Face personality, display vs UI roles, weight contrast, tracking, wrapping | Type strategy, not font cloning |
| Color | Canvas temperature, dark/light balance, accent deployment | Functional palette roles |
| Space | Cluster boundaries, gaps, optical balance, screen zones | Relational rhythm, not rigid distances |
| Shape/material | Corners, outlines, grain, shadows, icon style | Reusable shape and material language |
| Identity | Mascot, mark, illustration, imagery, voice | Mechanism for recognition |
| Interaction | CTA, familiar controls, affordances, states if visible | Expected user behavior and trust |

Prefer a concise mapping like this:

`Visible observation → likely effect → transferable rule → target adaptation → literal thing NOT to copy`

## Without visual references

Do not search for a famous aesthetic to imitate by default. Build an evidence-led direction from:

1. **The job:** what the person wants to accomplish and what they must understand first.
2. **The audience:** expertise, urgency, attention budget, accessibility, and decision risk. Avoid stereotypes.
3. **The brand:** existing visual assets and voice, or explicit positioning if the brand is new.
4. **The content:** real services, products, locations, results, proof, and imagery.
5. **The interface:** familiar patterns that reduce work and uncertainty.
6. **The signature:** one ownable, product-specific expression, if differentiation matters.

Generate 1 coherent direction with a concise rationale. An optional second contrasting direction is justified only if the brief is exploratory. When there is no usable brand material, treat palette and typography as proposals rather than claiming them as existing tokens.

## Generic example of principle transfer

**Observation from any strong reference:** a recognizable identity occupies a focal region, while primary controls are quiet and familiar.

**Underlying principle:** separate expressive brand moments from utilitarian interaction patterns.

**Possible translation:** for a professional service site, express identity through real case photography and deliberate editorial type while keeping quote requests and contact controls conventionally usable. For a technical dashboard, let data visualization and information architecture express specificity while controls remain standard. Neither outcome requires the same fonts, colors, or imagery as the reference.

## Three transfer levels

- **Principle only (default):** transfer hierarchy, deliberate contrast, restraint, brand/utility separation. Replace the style entirely for the target.
- **Similar emotional register:** preserve abstract feeling such as warm, bold, welcoming, or rebellious, but choose project-appropriate assets and type.
- **Visual recreation:** retain layout/look if explicitly requested, while handling permissions, original assets, responsiveness, and unavailable fonts honestly.

Always let explicit user fidelity requests override the default translation strategy.
