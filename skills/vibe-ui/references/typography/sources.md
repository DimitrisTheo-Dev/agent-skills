# Sources and limits

The ten directions and role examples are original editorial guidance, not tested rankings or copied
font pairings. Selected supplied Refactoring UI and User Interface Typography preview excerpts
informed hierarchy, baseline and line-height inspection. No source passages, fonts or books are
distributed.

[W3C Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html), checked 2026-11-11,
explains the 200% requirement and exceptions. Check
[Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) separately for narrow layouts.
Neither establishes a preferred typeface or universal body size. Verify font rights and script
coverage from the chosen font's primary source.

W3C Internationalization guidance on base direction and isolating inline text was checked
2026-11-18. [Document direction](https://www.w3.org/International/questions/qa-html-dir) ·
[Bidirectional inline markup](https://www.w3.org/International/articles/inline-bidi-markup/)
